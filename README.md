# CamLife (ជីវិតកម្ពុជា) - All-in-One Daily Life Assistant for Cambodia

**CamLife** គឺជាគេហទំព័រសហគមន៍ និងសេវាកម្មប្រចាំថ្ងៃទំនើប បង្កើតឡើងដោយបច្ចេកវិទ្យា **Vue 3, Tailwind CSS, JavaScript & HTML5/CSS3** ដើម្បីជួយសម្រួលដល់ការរស់នៅប្រចាំថ្ងៃរបស់ប្រជាជនកម្ពុជា 🇰🇭។

---

## 🌟 លក្ខណៈពិសេសចម្បងៗ (Key Features)

### 1. 🚨 លេខទូរស័ព្ទសង្គ្រោះបន្ទាន់ & អាជ្ញាធរ ២៤/៧ (Emergency Speed-Dial Hotlines)
- **1-Click Call & Direct Telegram**:
  - **117** ៖ នគរបាលជាតិ (សន្តិសុខ & បទល្មើស)
  - **118** ៖ បង្ការ & ពន្លត់អគ្គិភ័យ
  - **119** ៖ រថយន្តសង្គ្រោះបន្ទាន់ជាតិ SAMU
  - **1288** ៖ មន្ទីរពេទ្យគន្ធបុប្ផា (ព្យាបាលកុមារឥតគិតថ្លៃ ១០០%)
  - **1298** ៖ អគ្គិសនីកម្ពុជា EDC (រាយការណ៍ដាច់ភ្លើង)
  - **023 724 046** ៖ រដ្ឋាករទឹកស្វយ័តក្រុងភ្នំពេញ PPWSA
  - **1286** ៖ បេឡាជាតិសន្តិសុខសង្គម ប.ស.ស. (NSSF)
  - **1285** ៖ នាយកដ្ឋានប្រឆាំងបទល្មើសបច្ចេកវិទ្យា (Anti-Cybercrime)
  - **1280** ៖ ខ្សែទូរស័ព្ទជំនួយកុមារកម្ពុជា (Child Helpline)

### 2. ⚡ កម្មវិធីគណនាថ្លៃភ្លើង EDC (EDC Electricity Calculator)
- គណនាវិក្កយបត្រភ្លើងអគ្គិសនីកម្ពុជាតាមកាំពន្ធផ្លូវការ (1-10 kWh @ 380៛, 11-50 kWh @ 480៛, 51-200 kWh @ 610៛, >200 kWh @ 730៛ ឬអត្រាអាជីវកម្ម 740៛) ដោយស្វ័យប្រវត្តិ។

### 3. 💵 កម្មវិធីប្តូរប្រាក់ (NBC Currency Converter)
- ប្តូរប្រាក់ដុល្លារ ($ USD) ⇄ ប្រាក់រៀល (៛ KHR) ភ្លាមៗ តាមអត្រាស្តង់ដារធនាគារជាតិនៃកម្ពុជា ជាមួយប៊ូតុងជ្រើសរើសចំនួនប្រាក់រហ័ស។

### 4. ⛽ តារាងតាមដានតម្លៃប្រេងឥន្ធនៈ (Weekly Fuel Tracker)
- តម្លៃសាំងធម្មតា (EA92), សាំងស៊ុបពែរ (Ron 95), ប្រេងម៉ាស៊ូត (DO), និងហ្គាស (LPG) ធ្វើបច្ចុប្បន្នភាពរៀងរាល់ ១០ថ្ងៃម្តង។

### 5. 🛠️ ស្វែងរកជាងជំនាញ & សេវាកម្មដល់គេហដ្ឋាន (Technician Directory)
- ជាងម៉ាស៊ីនត្រជាក់, ជាងភ្លើង, ជាងទឹក, សេវាសម្អាតផ្ទះ, ជាងចាក់សោរ ២៤ម៉ោង, សេវាដឹកទំនិញ/រ៉ឺម៉កកង់បី។
- ចម្រាញ់តាមខណ្ឌ (ទួលគោក, សែនសុខ, ចំការមន, ដូនពេញ, ច្បារអំពៅ...)។
- ទាក់ទងតាមទូរស័ព្ទ ឬ Telegram ផ្ទាល់។
- ទម្រង់ចុះឈ្មោះជាជាងជំនាញថ្មី (Join as Technician Form)។

### 6. 🏥 មន្ទីរពេទ្យ & ក្តារជូនដំណឹងបរិច្ចាគឈាមបន្ទាន់ (Healthcare & Blood Donation)
- មន្ទីរពេទ្យរដ្ឋ និងឯកជន (កាល់ម៉ែត, គន្ធបុប្ផា, មិត្តភាពខ្មែរ-សូវៀត, ព្រះកុសុមៈ, រ៉ូយ៉ាល់ភ្នំពេញ, វិទ្យាស្ថានប៉ាស្ទ័រ)។
- ចម្រាញ់តាម៖ សង្គ្រោះបន្ទាន់ ២៤ម៉ោង, ទទួលប័ណ្ណ ប.ស.ស., និងឯកទេសកុមារ។
- ព័ត៌មានកម្រិតខ្វះខាតឈាមប្រភេទ O+, A+, B+, AB- នៅមជ្ឈមណ្ឌលជាតិផ្តល់ឈាម (CNTS)។

### 7. 🚌 មគ្គុទ្ទេសក៍ធ្វើដំណើរ & ឡានក្រុងរាជធានី (City Bus & Transit)
- ខ្សែរត់ឡានក្រុងភ្នំពេញ Line 1, Line 2, Line 3, Line 4A ជាមួយចំណតសំខាន់ៗ និងតម្លៃសំបុត្រ (ឥតគិតថ្លៃសម្រាប់សិស្ស ព្រះសង្ឃ មនុស្សចាស់)។
- ព័ត៌មានរថភ្លើងកម្ពុជា (Royal Railway) ខ្សែភ្នំពេញ-ព្រះសីហនុ និងភ្នំពេញ-ប៉ោយប៉ែត។

### 8. 🛒 សន្ទស្សន៍តម្លៃទំនិញម្ហូបអាហារប្រចាំថ្ងៃ (Daily Market Prices)
- តម្លៃមធ្យមនៃអង្ករផ្កាម្លិះ, សាច់ជ្រូកបីជាន់, សាច់គោ, សាច់មាន់ស្រែ, ត្រីរ៉ស់, ពងមាន់, ប្រេងឆា នៅផ្សារធំៗក្នុងរាជធានីភ្នំពេញ។

### 9. 📖 គន្លឹះរស់នៅ & សេវាសាធារណៈ (Living Guides)
- របៀបបន្តប័ណ្ណបើកបរនៅផ្សារទំនើប អ៊ីអន (Aeon), នីតិវិធីធ្វើ Passport, គន្លឹះសុវត្ថិភាពរដូវវស្សា និងបញ្ចៀសផ្លូវលិចទឹក។

## 🎨 UI/UX & បច្ចេកវិទ្យា
- **Vue 3**: Reactive State, Computed Properties, Single Page Application
- **Tailwind CSS**: Responsive Design (Mobile-First, Tablet, Desktop)
- **Khmer Fonts**: `Kantumruy Pro` & `Koulen`
- **Bilingual**: គាំទ្រភាសាខ្មែរ 🇰🇭 និង English 🇬🇧
- **Dark Mode / Light Mode**: រក្សាទុកដោយស្វ័យប្រវត្តិក្នុង LocalStorage
- **Bookmarks**: រក្សាទុកលេខបន្ទាន់ និងជាងដែលពេញចិត្ត

## 🚀 របៀបដំណើរការ (How to Run)

### វិធីទី១៖ ដំណើរការជាមួយ Vite Dev Server
```bash
# ដំណើរការ Local Server
npm run dev
```
ចូលទៅកាន់ `http://localhost:3000` ក្នុង browser របស់អ្នក។

### វិធីទី២៖ បង្កើត Production Build
```bash
npm run build
```

### វិធីទី៣៖ បើកដោយផ្ទាល់ (Direct Open)
បើកឯកសារ `index.html` នៅក្នុង Web Browser ណាមួយ (Chrome, Edge, Safari, Firefox) បានដោយផ្ទាល់។
